Разработка учебного микросервисного проекта для обработки счетов, построенный на событийно-ориентированной архитектуре с 
использованием Apache Kafka. Реализовал два взаимодействующих сервиса — Producer и Consumer — для асинхронной обработки 
финансовых транзакций

Основной функционал:

Producer-сервис (REST API, порт 8080) принимает HTTP-запросы на создание счёта, сохраняет запись в PostgreSQL со статусом NEW, 
затем публикует событие в топик Kafka invoice-created.

Consumer-сервис (порт 8081) слушает топик invoice-created, обрабатывает сообщение, изменяет статус счёта на REGISTERED и 
отправляет обновлённое событие в топик invoice-registered.

Producer-сервис также подписан на топик invoice-registered, получает подтверждение и обновляет статус соответствующей записи 
в базе данных.


Docker должен быть скачан и ЗАПУЩЕН на вашей машине!!!

Инструкция по запуску приложения:

Шаг 1. Скачайте проект к себе на машину.

Шаг 2. Откройте терминал. В терминале перейдите по адресу с содержимым проекта.

Шаг 3. В терминале введите команду: docker-compose up -d --build (сборка и запуск контейнера для приложения)

Шаг 4. Проверьте что все нужные контейнеры запущены. Для этого введите команду: docker ps. Вы должны увидеть список,
в котором будут указаны следующие сервисы: consumer-service, producer-service, kafka, postgres, zookeeper

Шаг 5. С помощью Postman (или т.п.) отправьте запрос для создания нового счета: POST http://localhost:8080/api/invoices.
В тело запроса передайте следующие значения (как пример): 
{
	"accountNumber" : "ABC-123",
    "amount": 9.01945
}

Этот запрос зарегистрирует новый счет в БД со статусом NEW. В ответе на этот запрос будет получено такое сообщение (пример):
{
    "id": 1,
    "accountNumber": "ABC-123",
    "amount": 9.01945,
    "status": "NEW",
    "createdAt": "2026-09-01T20:48:16.794000808"
}


И далее передасться сообщение для дальнейшей обработки счета в Consumer. Все произойдет автоматически.

Шаг 6. В терминале (в котором работали до этого) введите следующее сообщение (для перехода к БД, которая запущена в нашем контейнере):
docker exec -it postgres psql -U admin -d billing_db 

Шаг 7. Далее введите SQL-запрос, чтобы посмотреть актуальные записи в БД: SELECT * FROM invoices;
В ответе вы получите: 

 id | account_number | amount  |         created_at         |   status   
----+----------------+---------+----------------------------+------------

1 | ABC-123      | 9.01945 | 2026-09-01 20:48:16.794001 | REGISTERED

Статус REGISTERED будет означать, что наш счет был обработан консьюмером и далее передан в продюсеру для обновления статуса в БД.


Проверка асинхронной работы сервисов.

Шаг 8. Выйдите из контейнера postgres. Для этого в терминале введите exit.

Шаг 9. Остановите работу сервиса по обработке счета. Для этого в терминале введите: docker stop consumer-service

Шаг 10. Через Postman (и т.п.) отправьте новый запрос (например): POST http://localhost:8080/api/invoices

В тело запроса передайте следующие значения (как пример): 
{
	"accountNumber" : "ABC-321",
    "amount": 9.01945
}

Шаг 11. Выполните Шаги 6 и 7. Вы получите обновленные данные из БД.

Например:

 id | account_number | amount  |         created_at         |   status   
----+----------------+---------+----------------------------+------------

1 | ABC-123      | 9.01945 | 2026-09-01 20:48:16.794001 | REGISTERED

2 | ABC-321      | 9.01945 | 2026-09-01 20:51:13.560016 | NEW

Вы увидите вашу крайнюю запись со статусом "NEW". Из-за того что наш сервис consumer-service  остановлен, наш счет не был обработан.

Шаг 12. Выполните Шаг 8, после чего запустите наш consumer-service с помощью команды в терминале: docker start consumer-service

Шаг 13. Повторите Шаги 6 и 7. Вы увидите, что наш крайний счет был обработан после запуска нашего consumer-service:

 id | account_number | amount  |         created_at         |   status   
----+----------------+---------+----------------------------+------------

1 | ABC-123      | 9.01945 | 2026-09-01 20:48:16.794001 | REGISTERED

2 | ABC-321      | 9.01945 | 2026-09-01 20:51:13.560016 | REGISTERED
